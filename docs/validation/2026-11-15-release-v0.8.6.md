# v0.8.6 发布验收（2026-11-15）

本版包含可选多聊天迁移、聊天重载时历史指令基线修复，以及下述提示词调整。完整1073项回归、9组主题／宽度和既有保存交互均通过；普通MVU与转换卡来源各2条聊天的实际SQLite迁移、重开读回及源文件不变核对通过，详情见[聊天迁移验收](2026-11-15-chat-transfer.md)。

本版将逐表重复的通用 JSON／SQL 更新说明集中到已有 `[M2SJK]填表适配说明` 条目，各表保留 JSON 列标识、作者业务约束和具体 SQL 示例。自由格式更新规则不能完整按 YAML 提取时，报告明确结构识别回退与原文保留，不将其等同于原 MVU 无法更新。变更见[更新日志](../../CHANGELOG.md)，当前约定见[数据映射](../data-model.md#json-列的-sql-局部更新)。

## 升级范围

说明变化作用于新转换产物；已有卡需从原卡重转，并同步角色卡、模板及世界书，填表时包含适配说明和作者更新要求条目。数据布局、初始化数据、约束与作者运行时脚本不因本版变化。上述提示词调整没有新增模型协议、运行时世界书选择检查或注释标记；聊天迁移另有可选面板和批量预检弹窗。

SQLite 实际执行确认了保留通用说明的依据：直接传入的对象文本可能被存为 JSON 字符串，`json(...)` 可保留对象类型；JSON null 容器不能直接当对象写入子路径；`json_patch` 的 null 会删除键。说明只覆盖这些操作差异，没有增加完整函数教程。
