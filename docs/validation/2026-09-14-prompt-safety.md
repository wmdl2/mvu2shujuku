# 字段说明与 SQL 示例保真验收

版本仍为 0.3.18 未发布，Node 22.23.2。此批修复已确认的三个局部问题，没有重新开展旧综合审查。

## 修改范围

- 字段说明和规则逐列显示，使用实际列名；不再把相同约束的多个字段折叠成模板标签。
  保留每个字段的独有描述、多行说明、范围、格式、枚举与业务条件，以及可见只读字段的含义。
  关联系统说明仅在逐字等价于生成的来源提示时去重，不因某列承担标识职责删除作者描述。
- note 使用「字段说明与规则」，不生成空标题。表头/DDL 仍提供列名，内部与私有字段的可见性不变。
- get/list/val 与 entries 回调按代码位置、作用域和参数绑定扫描，排除字符串中的示例、同名参数、
  无关 data 变量及重新赋值后的误补；保留原有附属组读取、helper 索引、合法闭包及回调。
- SQL UPDATE 示例按范围、枚举、数值、布尔和 JSON 编码选择值；INSERT 保留初始行/默认值策略，
  空值兜底也检查类型约束。关联数组示例填写全部关联字段并完整定位。示例前说明必须按本轮数据
  与规则确定真实操作，不能直接照抄。保留原有 JSON 路径示例和空容器守卫。
- 默认双模式继续由 SP 提供当次 SQL/native 协议；没有把两套可执行语法同时塞进共享触发条件。
  界面提示修正为实际行为，不再声称双模式包含逐表 SQL 示例。未新增模式切换或物理外键。
- 构建日志改用 UTF-8 字节数，避免把 JavaScript 字符数标为字节。

## 后续边界

本批以内容完整和安全为先，没有承诺提示词变短。缺少非空类型证据时不猜可空列类型，无法安全
推导的对象示范保留操作说明，不编造字段或用空对象覆盖。扫描仍是可识别语法的静态补充，
不承诺执行任意前端代码。动态 VWD 描述、整行/整组 nullable、自定义 Zod 变换等既有边界不变。
物理外键和新增关系一致性诊断仍为独立候选，未作为本轮已完成功能。
