# 真实 JavaScript/Zod Schema 执行改造

日期：2026-10-05；产品版本仍为用户已选的 0.5.0。本记录接续[静态解析根因诊断](2026-10-05-conversion-root-causes.md)，不改变旧版本验收的受测指纹。

## 实现与边界

启用的本地或已下载注册 Schema 通过生产 `convert`（Node）／`convertWithRemoteSchemas`（浏览器）执行。Acorn 8.16.0 选择词法绑定、必要声明、赋值与登记调用链；Zod 4.4.3、Lodash 4.18.1 及 JavaScript 引擎实际构造 Schema。固定依赖、锁文件、重建工具和许可证随仓库提供。旧静态解析辅助 API 仍供禁用声明、其他参考扫描使用，不是启用注册 Schema 的生产权威。

Node 在独立 Worker 的 VM 中执行，不注入进程／文件系统 API，禁止动态代码生成；浏览器在 opaque-origin sandbox iframe 创建可终止 Worker，CSP 禁止网络访问。构造限时并清理资源。不会启动切片外的界面、事件和业务；必要但未知的导入不能自动执行。

字符串转义、计算属性、简写、词法作用域、辅助函数、循环与对象组合由实际引擎决定，不再分别补写文本语法规则。具名启动函数里的登记也沿调用链选取。联合与任意 transform 的未知输出保留完整 JSON；不执行变换／默认函数来猜测输出类型。标准类型、枚举、描述、静态默认值及可表达约束从实际对象读取。`.required()`／`nonoptional` 恢复必填；正则、整数、排他边界等未落入数据库的约束明确报告为运行时校验。

时间和随机值不被转换时的环境固定成今后开局默认值。例如 `z.number().default(Date.now())` 的当前时间不能替代未来运行时值；`default(() => Date.now())` 也不作为静态初值。环境依赖下仍可确定字段名时保留已有值的完整 JSON 并报告；无法确定字段名、必要根结构或登记结果时中止。

这不等于所有 JavaScript 应用均可转换：任意宿主环境、必要外部模块、动态 Schema 提供函数、运行后新增根结构、不同 Zod 主版本和整卡业务仍有边界。运行时继续使用原角色脚本登记的实际 Schema；状态栏读取不再下载／分析源码。直接数据库填表仍按数据库协议和约束，不自动经过 Mvu 候选校验。

## 行为验证

公开契约通过实际生产路径验证等价语法、作用域、登记调用链、静态／动态默认、环境依赖、完整 JSON 写读、进程访问限制与超时。旧测试中的 `prefault(...).min(...)` 不属于受测 Zod 4 的有效 API 链，修正为 `min(...).prefault(...)`，业务预期未降低。旧脚本保留夹具的普通空对象也改为实际空 Zod 对象。

新聊天只有空表头、无存档时读取卡内初始模板；已存档的可选空 JSON 字段保持缺失。公开夹具覆盖空聊天、尚未保存的第一开场和保存后的字段删除。

15 张私人社区卡均重新生成 JSON／PNG、模板、报告和桥。62 组原始开场输入经各自实际作者 Schema 归一化，再调用生产 writer／codec，零差异；220 张表、221 行初始数据通过 Python SQLite 的真实 DDL／插入／读回。15 PNG 与对应卡 JSON 一致，120 个保留／生成脚本语法通过。表数减少来自未知变换输出合并为完整 JSON；不宣称等价迁移任意业务或已逐张正常游玩。

浏览器组件使用实际根目录构建，三个等价属性样本、网络限制和超时共 5 场景通过；网络请求 0、残留执行 iframe 0、页面错误 0。
