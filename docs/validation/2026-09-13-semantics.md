## 边界

V2 事务来源不明时只通知，不自动补写。旧楼公共 CRUD 的多步修正没有额外跨操作事务保证。
解析/事件的 display、delta 不作为独立历史状态持久化。主动兼容差异及各入口提交规则见
[运行时契约](../runtime.md#更新入口与提交契约)。

隐藏表格列不隐藏原始聊天、混合 JSON 内的私有叶子；使用者须按转换报告检查 SP 上下文规则。
根目录 index.js 与隔离安装包构建一致、语法及版本检查通过，版本仍为 0.3.18，尚未提交或发布。
