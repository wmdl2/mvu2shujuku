# 0.5.0 远程 Schema 与多开场验收

日期：2026-10-05。用户已批准转换时分析远程源码、运行时复用原脚本登记接口、可证明时固定版本，并选择 0.5.0。源码、manifest 和根目录产物已升版；本轮未提交或推送。前序静态默认值和社区语料修复见[首批记录](2026-10-05-community-card-conversion.md)。

## 最终行为

转换界面调用 `convertWithRemoteSchemas`，对已启用且可识别的变量结构模块下载源码，只做静态分析，不执行下载代码。支持调用方提供同一 URL 的本地快照。下载有超时、大小限制及最多32项、5分钟的源码缓存，失败可重试；局域网 HTTP 缺少 SubtleCrypto 时仍能计算 SHA-256。

默认转换卡仅保存 URL、运行时 URL、SHA-256、commit 和接入方式。运行时继续 import 作者模块，通过原 `registerVariableSchema` 登记取得实际 Zod 对象，数据桥使用该对象校验候选数据并执行变换。模块无需额外导出 Schema。状态读取和普通写入不会再次下载源码做分析；页面或脚本 iframe 重建时，原模块按浏览器正常加载和缓存规则处理。远程模块及其外部依赖仍须可访问。

jsDelivr GitHub 链接尝试定位 commit，只有固定 URL 的内容与分析快照逐字节相同时才使用该 URL。3个实际远程模块中，2个成功固定 commit；另1个原有精确版本链接的 GitHub 查询返回 HTTP 422，保留原版本 URL 并报告，未用其他版本代替。主模块固定不代表其传递依赖全部固定，也不保证历史标签永久可恢复。显式核心选项允许本地化支持的模块；本批无需本地化，未自动内联作者源码。

多开场只合并布局结构。首分支缺失、部分分支缺失或跨分支类型变化的根组采用可缺失完整 JSON，各分支仍独立加载自己的初值。完整 JSON 列独占后代路径，展示引用不再生成会覆盖它的重复叶子列。未声明路径的缺失字段不制造父对象；Schema 要求的空父对象以及旧布局语义保留。未知 JSON 的大初值不会重复复制进 DDL DEFAULT。

同批删除记录后，动态扩展字段按最新数据库导出快照及业务键定位；导出返回克隆对象时同样有效，连续扩展字段不会互相覆盖。

62个输入来自原卡世界书 InitVar 或各个开场，不以生成表格自读结果冒充原始数据。能取出实际 Schema 的原模块在隔离组件中用实际 Zod 归一化，再经过产品写入器读回。组件提取不启动整张卡的业务；含自带引擎或禁用原脚本的卡不因此变为完整运行时兼容。

宿主固定 SillyTavern 1.18.0 / `8172dcd0`、酒馆助手4.11.3 / `87ca341a`、龙血玄黄·数据库1.2.5 / `33f85944d3371586ba5a3c80ab9fc72fdaeeaacc`，Node22.23.2，角色浅加载关闭。公共夹具经过生产转换、原模块登记及实际数据库保存，覆盖数值变换120→50、可缺失根组、数值与对象切换、必需空父对象、删行后扩展字段保存及重载。读取与写入检查在当前脚本完成登记之后冻结下载计数。

中间全量回归发现省略缺失字段会丢失必需空父对象，已改为仅标记未声明父路径，未改旧冻结预期。中间宿主发现数据库克隆导出导致删行后的旧行号告警，已使用删除后的新快照定位；另一次下载计数断言缺少脚本启动前置条件，夹具已等待实际登记完成。最终结果使用以上修复后的冻结构建，不混用中间构建的通过记录。

公开复现入口：

```bash
node test/run-tests.js --grep '远程结构|多开场结构|Schema 读回'
node test/run-tests.js
node build-extension.js
node --check index.js
MVU_SP_TEST_COMMIT=33f85944d3371586ba5a3c80ab9fc72fdaeeaacc node test/real-host.js --only=remote-schema
```

语料包含私人角色卡，不进入公开回归依赖；公共样本在 `test/remote-schema.js` 和 `test/remote-schema-host.js`。SQLite 回归需要可启动 Python 子进程，宿主依赖见[开发指南](../development.md)。
