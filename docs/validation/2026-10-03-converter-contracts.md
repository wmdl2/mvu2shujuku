# 通用转换契约修复（2026-10-03）

版本 v0.4.8，基于 v0.4.7 / `e9ea23f`。修复按声明、路径和实际输出契约实现，不依赖角色卡名称、业务列名称或私有卡正文。

## 原因与修复

| 问题 | 根因 | 通用修复 |
| --- | --- | --- |
| 点号键写入后变成多层字段 | 操作规划把路径数组合并为字符串，再按点号拆分 | 全程保留路径段；内部索引用数组 JSON 编码 |
| 空键丢失 | 将空字符串当成字段不存在 | 区分缺失与空键，覆盖多层关系的祖先键 |
| 特殊原型键保存不正确 | 对普通对象直接赋值或读取继承属性 | 创建 own-key，按自身属性读写；初始化、合并、写入和恢复使用同一边界 |
| 空根层标量字典没有值列、布尔变成文本 | 根层与嵌套实现分叉，过度依赖初值 | 共用声明类型映射；接受字符串声明的 `string`/`text` 别名；混合/null 使用 JSON 标量编码 |
| 规则已删除却没有进入实际说明 | 把 schema 中存在规则误认为迁移完成 | 解析保留来源路径；实际 Note 渲染记录凭证；清理前核对完整落点 |
| 未知 `type` 等内容被连带删除 | 按元字段名称推断可删除职责 | 仅清理已识别的声明元信息，未知内容保留 |
| 有限绑定、提醒重复残留 | 展开后的目标路径与原 YAML 来源路径混用 | 独立记录来源和展开目标；凭实际迁移结果逐项拆分提醒 |
| XML 包裹的纯输出协议漏删且误分类 | 包裹语法识别不全，保留原因用统一标签 | 识别完整 `<Format>` 与结构输出包装；剧情/EJS/未知职责保守保留并准确报告 |
| 禁用结构脚本仍补默认值 | 没有区分结构参考与生效声明 | 禁用脚本仅参考结构，移除默认语义并允许缺失；启用声明优先 |
| 任意自动处理逻辑容易被误认为已承接 | 静态结构不能等价表示任意程序行为 | 不执行任意 transform；coerce、钳制等行为差异明确列为人工项 |
| 长初值复制到新增示例 | 示例优先使用真实记录及默认载荷 | 使用类型短值及枚举/范围；不复制初值，INSERT 使用新键占位 |

这些漏洞共同来自不同阶段对同一概念作了不同解释：路径与显示文本、声明与样本、结构识别与实际提示落点、静态信息与运行行为。以前的正常键和非空样本容易掩盖差异；仅验证结构或操作返回成功也无法证明值与类型正确。新回归覆盖空/非空、根层/嵌套、特殊键以及真实写入后的恢复值。

## 使用边界

已有转换卡应重新转换，并使用新模板创建聊天；不自动修改旧聊天的布局。两种填表模式共用业务说明，由宿主当前请求提供语法和编号，不增加第三种输出协议。

禁用 Schema 默认值和任意自定义运行逻辑按已确认的保守策略处理。报告区分合法标量字典、已移除的纯输出协议、未知职责保留和未自动承接的运行约束。未绑定的动态规则、复杂 EJS、外部业务脚本仍可能需要人工处理；固定响应验收不证明真实模型质量。

公开复现入口：`node test/run-tests.js --grep "转换契约|声明路径|SQL示例保真|提示输出冻结"`；完整测试：`node test/run-tests.js`；双模式隔离宿主：`node test/real-host.js --only=converter-contracts`。
