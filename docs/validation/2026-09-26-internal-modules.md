# 内部模块边界与 JSONPatch 修复依赖

本批将既有 MVU 命令处理从运行时协调层提取出来，并整理浏览器装配清单。SP 填表方式、
存储职责、卡片布局与版本号保持原样；无需迁移已有聊天。

## 实现

- `src/mvu-commands.js` 提供命令解析、命令信息转换与内存应用。六个函数体与提取前一致，
  只导出运行时需要的四个入口；值解析和参数切分留在模块内部。
- `src/extension-runtime.js` 通过工厂调用命令模块，继续负责事件、会话和提交。解析库通过
  `getMvuYamlLibs` 注入；此前运行时引用了未绑定的同名函数，异常被捕获后导致 JSONPatch
  修复回退无效。现有内联 jsonrepair 可修复尾逗号等格式问题；不可用的输入继续忽略。
- `src/mvu2shujuku.js:assembleExtension` 用有序清单注册工厂。特殊资源的装载位置与运行时
  启动顺序保留，浏览器仍使用单文件产物。

命令模块不会发起模型请求。表格提示和布局没有因本次提取增加内容；本批不作性能提速声明。
