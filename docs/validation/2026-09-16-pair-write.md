# 旧式 pair 写入验收

脚本写回 layout 明确登记的 `[当前值, 说明]` 时，写入器先取当前值，再按列类型编码。
文本写字符串、数字保留数值、布尔写 `0` / `1`、`jsonPairOptional` 保留 JSON 的 null / 缺失语义。
新建行从保存的原始对象编码，避免数组先被转成“值,说明”文本。普通数组和 JSON 对象不拆包。
这项修复默认生效；VWD 动态说明仍是默认关闭的实验，读回使用 layout 中的静态说明。

## 回归覆盖

| 场景 | 断言 |
| --- | --- |
| 单例文本 pair / 说明变化 | 只写当前值，读回仍使用静态说明 |
| 已有行数字、文本 pair | 载荷是物理标量，读回当前值准确 |
| 新增行数字、布尔、文本 pair | 实际调用 insertRow；不传数组/布尔物理值，读回准确 |
| 布尔 pair 更新 | 分别强制经过 updateRow 与 updateCell，读回为 true |
| nullable pair | 显式 null 和删除后的缺失均保留，不恢复初始文本 |
| 普通数组、JSON、实验拒绝与默认结构 | 相关回归保持既有契约 |

各写入出口共享编码结果；上表表示本次直接断言的路径，不表示对每个类型和 API 的所有组合
都做过独立实机验证。公开转换冻结不变，写入行为对照 `test/vwd-static-pair-fixed.json`。
