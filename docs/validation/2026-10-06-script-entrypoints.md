# v0.5.1 脚本入口与大资源转换

## 改动

`schema-execution.js` 的 AST 来源和作用域分析同时供转换接入与实际构造使用。支持静态登记别名、命名空间成员、字面量动态导入的解构声明和赋值；排除同名局部函数。已有远程打包模块的导出转发构造路径继续保留，运行时仍通过原工具的变量结构登记接口接入。

已知 MVU 引擎的短延时、双 CDN 回退加载器，仅在 AST 能证明其只有加载及错误诊断时删除。未知地址、计算地址或混合业务继续保留。字段回调扫描改用保持偏移的字面量遮罩；无 `stat_data` 的内容跳过无效 EJS 重写。

## 验证

- 入口与真实构造相关回归：21 项通过；此前入口、类型、字段及 EJS 相关批次 71 项通过。
- 最终 713 项无遗留失败：前 362 项通过；SQLite 子进程在受限环境等待输入结束，保留进度并在正常环境补跑剩余 351 项，350 通过、1 个浏览器夹具遗漏依赖。改用实际根目录构建包后该项补跑通过。没有为夹具修订重复整套。
- 15 张既有社区样本的布局与完整模板，和已验收的类型修复基线逐项一致。
- 动态登记公开宿主用例：原生及实际 SQLite 初始化、变换、档案保存重载、未知根组拒绝通过，浏览器异常为 0。
- 指定大资源卡的浏览器转换生成 24 表，登记键 1 个；原引擎加载器移除，11 个原作者结构／业务脚本与数据库桥保留。
- 指定卡原生及实际 SQLite 实机通过：原作者 Schema、扫描、主线调度及手机 0.14.0；JSON Patch／变量替换、真实数据库读回、刷新重载保留小数 `3.75` 和嵌套 `false/null/1.25`，浏览器未捕获异常为 0。初始化按作者异步主线派生值完成判定；两个模式分别验证，避免测试副本的相同脚本 ID 影响生命周期。

实机固定 SillyTavern 1.18.0、酒馆助手 4.11.3、数据库 1.2.5（`33f85944d3371586ba5a3c80ab9fc72fdaeeaacc`），关闭角色浅加载。参考数据库更新到 `1a5ffdb3ef8817452c370c6cfef7cac86683d7cc`，未替代受测版本。

本地 Node 暖转换采样从约 4.9 秒变为 1.8 秒，输入为同一卡的已解析 JSON；不包含文件读取、浏览器 Worker、界面生成或宿主导入。浏览器完整 PNG 转换在本机约 21–23 秒，不能把 Node 数据当成界面耗时或通用速度承诺。原作者外部依赖仍需可访问，默认没有把下载内容内联进插件或卡片。
