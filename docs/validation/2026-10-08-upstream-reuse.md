## 实际替换

| 原实现 | 现在使用的实现 |
| --- | --- |
| EJS 标签正则、自行排除注释和转义标签 | 冻结 EJS 的 `Template.generateSource` / `scanLine` 识别实际代码范围；观察原解析过程，不执行作者代码，改写仍保留原文偏移。 |
| EJS 改写中的字符串、注释、正则和模板字符串扫描 | 已有 Acorn 的 tokenizer；字面路径使用 `parseExpressionAt`，支持原生字符串转义和无插值模板字符串，不将拼接表达式误认作字面量。 |
| `js-source.js` 中另一套手写词法扫描 | 同一 Acorn 依赖提供 token 范围；源码拆分、替换、括号定位保留既有契约。 |
| 状态字段扫描中的独立 EJS 正则 | 使用转换器相同的 EJS 解析入口；区分原始 TH JavaScript 和混合 HTML/EJS，避免把正文与标签交给 JavaScript tokenizer。 |
| EJS getter 的逐层读取、setter 的容器创建 | Lodash `get`、`cloneDeep`、`set`、`unset`；保留现有写入入口与原型键防护。`undefined` 按原 setter 的删除语义处理。 |

运行时仍由宿主提示词模板执行作者 EJS。本次新增的冻结库负责转换时解析，不取代宿主执行器，也没有运行时下载。非数据库变量的原生接口保留。

`src/vendor/ejs-parser.js` 保留第三方文件的 Apache-2.0 声明与完整许可。来自提示词模板 1.17.9 的 commit `d6f520d149aba146305b0b781ddd691d449c28d2`，该文件导出的 EJS 版本为 3.1.9；原始库字节 SHA-256 为 `66b3c84f33adbf154950e18cb55704062e3fa5e2f4e69001f6df296d11548d54`。仅增加自包含工厂外壳，库内容未编辑。Acorn 和 Lodash 复用已有依赖。

## 仍需必要适配的部分

动态变量路径、历史消息选择和特殊变量选项仍未完整接管；宿主验证继续复现动态路径写入原生变量但数据库不变、历史读取返回当前值、历史写入误改当前值。复用解析器和公共库没有自动消除这些缺口。

提示词模板的变量实现绑定了其宿主消息数组、全局/聊天变量及内部缓存，公开接口没有让调用方替换整个存储后端的参数。因此需要保留作者代码由原执行器计算实参，复用宿主公开接口处理原生变量，对数据库变量建立统一适配入口；不能通过临时替换共享消息/缓存来伪装数据库后端。历史写入还需核对数据库存档链，支持范围与策略尚未实施。本轮没有复制 AGPL 变量源码，也没有把这些工作标为完成。
