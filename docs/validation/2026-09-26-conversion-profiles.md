# 转换配置与外部表合并模块

## 范围与契约

`src/conversion-profiles.js` 将配置保存数据、匹配和外部表合并规划从运行时入口分离。
模块通过显式依赖取得模板来源、模板合并与表设置方法，返回候选结果，不更新界面或保存宿主。
`extension-runtime.js` 保留读取来源的公开接口、确认弹窗、设置保存、产物刷新与状态提交。

- 配置格式继续使用 version 1，按来源及名称区分外部表；来源内 UID 失配时仅按唯一同名表回退。
- 每个来源读取一次最新版。先并入外部表，再覆盖保存的表设置；旧配置缺少注入字段时保留当前值。
- 原确认阈值、摘要和取消行为保留，包括重复来源引用的逐条匹配统计。
- 原始模板、来源和配置不被规划修改。拒绝时返回新转换的基础模板；手动合表仅在产物刷新成功后
  提交结果和来源引用。没有改变已存在聊天的数据或数据库填表方式。
