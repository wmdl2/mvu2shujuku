# 声明路径、固定对象与深层空字典验证

日期：2026-10-01。基线 `d00affc`，行为验证版本 0.4.2，发布版本 0.4.3。本批未修改 SP 或 MVU 上游。

## 根因与修复

- 顶层对象的初值子对象共享字段时，原推导会把已注册的固定 `z.object` 猜成行表，随后又把固定身份展开为列，造成两套结构重叠。固定声明现在优先决定单例；显式 MVU 对象元数据保持优先。
- 固定容器内的深层字典依赖子表简称找声明，单例附属字典还未读取 value Schema。初始为空时会回退为文本「描述」，丢失标量编码和对象字段。现在沿完整逻辑路径读取 record 的键说明、值类型、字段、缺省值、范围和枚举；二段简称只描述直接字段，不传播到所有后代。
- YAML 普通字段的中文限定漏掉中英文混合名称；容器展平后整体 check 无匹配列。现在复用标识符校验并按实际承载路径保留整体/集合规则。
- 原规则条目的删除判断只证明 YAML 可解析，未证明业务规则已迁移。现在用实际规则集合核对 check/note；初值文本与规则碰巧相同不算已迁移，未定位规则保留在原条目并报告。

实现位于 `src/schema-layout.js`、`src/mvu2shujuku.js`，没有卡名、平台名或私有字段特例。旧转换卡和聊天不自动改变；重新转换原卡并使用配套新模板建立新聊天。
