# 窗口引用与开场保护快照回收

## 修复范围

接管过的 iframe 过去一直被顶层原始接口注册表强引用，窗口移除及切卡还原后仍留在列表。
现在 `runtime-globals.js` 在扫描后只保留当前窗口，离线窗口先尝试还原再移出列表。
还原失败的记录只以窗口为弱键保存在 `WeakMap` 中；旧桥仅写 list、未经过新登记的记录也会
先转入弱键记录。成功还原后删除旧记录，再接管时采集新的真实接口。后来安装的非本插件函数不覆盖。

初始化函数去重改用 `WeakSet`，避免同会话中不断出现的新 iframe 函数延长旧窗口生命期。
Node 与浏览器装配均使用同一工厂，无新增弱引用枚举器或独立回收计时器。

开场保护复用原 2 秒轮询清理过期、未启用和已解除的状态；切到其他卡后仍清理。
解除保护立即删除登记。有效的 30 分钟保护不按数量淘汰，正在异步恢复的状态不移除，结束后才允许回收。

消息/提交去重记录未改。直接按固定数量淘汰可能让旧回复、swipe 或提交再次执行，需单独验证。
宿主写入顺序、表结构、数据库保存及回放协议没有改变。
