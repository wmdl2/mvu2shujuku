# 插件保存时同步转换世界书（v0.7.0）

用户同意插件保存时处理同名世界书冲突，备份作为可选项、默认不勾选。下载后原生导入不在本轮范围内。

保存行为：不存在就创建并绑定；完整内容相同则复用；不同则显示更新原书、另存新书、取消保存。更新可选下载完整旧原生世界书 JSON，包含条目和其他设置，不额外创建备份世界书。另存使用未占用编号名称，并同步本次保存副本的内嵌书名和绑定；转换结果和下载文件保持原名称。取消不创建卡、不执行失败下载回退。

世界书格式委派宿主 `convertCharacterBook`。直接接口检查 HTTP 状态，确认后再次读取当前书以发现等待选择期间的编辑；写入后直接读回复核再同步缓存与事件。未标记卡拒绝同步，无非空内嵌书则沿用卡保存。不支持的文件名失败并保留下载回退，不能静默绑定错误名称。

覆盖会替换转换后的完整世界书，影响所有绑定角色；旧书的编辑与设置可通过完整 JSON 备份保留。备份下载提示只证明已发起下载，实际文件需确认浏览器下载结果。世界书与角色卡没有联合事务，也没有宿主原子比较交换锁；接口失败后可能已经写入，不自动删除或回滚不确定的结果。覆盖世界书不迁移旧聊天表格。
