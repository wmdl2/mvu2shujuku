# 选中候选的变量接口（2026-11-21）

- 酒馆助手的普通 `getChatMessages` 同时返回 `data` 和兼容字段 `swipes_data`。带 `include_swipes: true` 的调用只返回候选形态。本批让这两种调用的已选候选都读到同一份数据库快照。读取副本与回放缓存隔离，未选候选沿用助手的原始返回。
- 原生助手收到 `data` 时按单候选写入。转换卡沿用这个语义，普通读取结果可以通过 `data` 写回。提交前后核对楼层和候选归属，避免异步回调或保存等待期间切换后改到新目标。独立的 `swipes_data` 状态写入继续明确拒绝。

### Windows 隔离环境

Node 在复制固定依赖时提前退出。通过 PowerShell 预置同版本扩展，核对安装指纹后复用。酒馆的默认内容复制也提前退出，此公开合成夹具通过隔离配置的 `skipContentCheck: true` 继续运行。

## 候选切换与延迟通知
