# 业务规则清洗保真验收

版本仍为 0.3.18 未发布，Node 22.23.2。本批接续[字段说明与 SQL 示例修复](2026-09-14-prompt-safety.md)，
修复规则清洗误删含义的问题（R06），未重新开展已完成的综合审查。

## 问题与修改

旧清洗逻辑仅凭「指令」等关键词删除整行或括号内容。例如「不要在没有收到管理员指令时修改
授权状态」会消失，「权限为冻结时保持原值（收到解除指令后才可修改）」会丢掉解除条件。
这会使表格中的规则与原规则不同，不能作为提示词精简接受。

- 保留普通业务指令、英文名称、作者提供的路径、括号条件以及混合业务参数。
- 完整识别的容器更新警告改为只修改变化内容、保留其余内容的说明，混合业务文本不整行删除。
- 完整 `op: delta/replace, value: …` 标量参数改为增量或新值说明，保留实际参数值。
  非有限数字、不支持的类型、表达式或混合业务保留原文。
- 保留原有超限限制及多字段同步更新义务；改写数组删除写法时保留括号中的删除条件。

## 边界

本批优先保留含义。无法可靠拆分的混合规则可能仍含原 MVU 操作名，不承诺理解任意自然语言或
执行任意业务条件。没有新增列、改变 layout、迁移旧聊天或启动宿主服务器；沿用前批已验证的
运行时行为。真实模型填表质量仍由实际场景观察，不把合成回归当成模型效果保证。
