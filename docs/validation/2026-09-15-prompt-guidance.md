# 特殊操作提示验收

版本仍为 0.3.18 未发布。本批完成特殊操作提示收尾与成本增量测量；没有加入外键、手动诊断或
VWD 动态说明存储，也没有重做已完成的综合审查。

## 修改与回归

- 关联记录示例包含全部关联字段及本条目标识，使用实际列名，注明占位值不能照抄；其他来源下
  的同名记录保持不变。默认双模式继续由 SP 提供可执行协议。
- 数组明确来源内数组序号、native 提示的 0 基整表行号、SQL 实际 row_id 三者的区别。
  native 不按不可见的物理 row_id 定位，SQL 不按显示顺序推算 row_id。
- 作者说明、JSON 路径指导、关联操作义务及已有 SQL 示例初值/默认值和类型保护均保留。
- 针对性 16 项通过；最终全量 379 项通过、0 失败、0 跳过。新增回归在 `test/table-prompts.js`。

## 隔离宿主

命令：`node test/real-host.js --only=prompts --filter-initvar --relation-prompts`。
公开样本为 `test/prompt-guidance-card.js`，版本沿用[固定环境](2026-09-11-host.md)。
SP 受测 `5c53f795`，本次参考源码更新为 `8646e5cc`，两者不混同。

运行 `2026-09-15T03-12-52-821Z`：

| 验证 | 结果 |
| --- | --- |
| 来源乙的第 2 条日志 | 来源内索引 1，native 整表行号 4，SQL row_id 5 |
| native / SQLite 实际填表 | 各 1 次本地固定响应，只更新目标日志；其他日志不变 |
| 保存与重载 | 修改保留 |
| 删除更新所在楼层 | 恢复原始日志及状态 |
| 业务事件 | 两种模式各 1 次，异步修正正常保存 |
| 浏览器异常 | 0 |

第一轮夹具误将普通 TEXT 日志按 JSON 解码，失败不计为通过。按 schema 编码修正，并捕获
路由回调异常交回主流程收尾；只复验相关宿主，没有因夹具修改重跑产品全量。固定响应通过不
证明真实模型准确率提升。

生成包 1,406,719 个 JavaScript 字符、1,560,483 个 UTF-8 字节，语法与版本通过；根目录和
隔离安装包逐字节一致。验收后核验并关闭专用服务器。本地用户样本重新转换，15 表、layout、
数据和 DDL 不变，原 PNG 未修改。成本结果见[增量测量](../benchmarks/prompt-2026-09-15.md)。
