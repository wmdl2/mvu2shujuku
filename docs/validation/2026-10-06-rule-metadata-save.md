# v0.6.0 规则迁移、正文分流与保存验收

本轮新增通用规则迁移、正文与填表世界书分流及保存进度，因此以 v0.6.0 发布。行为验收期间使用 v0.5.2 候选版本；下文保留各批实际受测构建指纹，最终发布仅调整版本标记及文档。

## 修复范围

`UpdateRules` 等作者分组标签不是 MVU 执行接口。解析器共用完整文档解包，支持无属性配对标签、常见文本围栏和有限嵌套。执行标签、动态 EJS、不完整外壳、相邻片段和混合正文不猜测拆解；部分承接的规则恢复原包裹形式。

分组散文以显式逻辑路径或准确组标题定位到表格，保留条件和续行。`valid_paths`、`allowed_paths` 等是明确支持的作者约定，不是 MVU 标准。完整输出格式在删除前单独提取其中可定位的业务定义；未知字段不套用路径或权限语义，未知路径、补充键和无法拆解的说明保留并报告。保留内容标明旧输出语法由数据库协议接管，只删除已确认的格式块。删除依据是目标表最终说明中的实际迁移凭证，宏与安全正则转换后仍核对最终文本。

按用户确认的收敛方案，撤回逐表原变量路径、类型和来源引用的新增说明，普通模板沿用 DDL 和列说明；原路径映射仅写入报告。业务规则使用实际布局列名，JSON 内部保留相对于实际 JSON 列的路径与必要结构说明。布尔式、条件式、未识别续行以及只读/可写冲突保留并报告；类型冲突不改 DDL，也不叠加另一套类型提示。明确的全表只读默认更新频率为 0，用户配置优先；部分只读不会关闭整表自动填表，脚本与手动填表仍可更新。这些提示不构成数据库访问控制。

异步入口复用一次角色卡解码，浏览器大文本编码改为分块拼接。保存头像只移除旧 `chara`、`ccv3` 数据块，保留像素和其他 PNG 元信息；完整转换卡数据照常保存。转换和保存共用操作锁，保存弹窗显示阶段，成功或失败均恢复按钮。

固定响应验证请求和接口路径，不代表真实模型剧情质量；Android、完整路线和所有作者模式未在本轮遍历。原作者可选的肖像目录在隔离数据中缺失，使用作者既有回退；数据库的发送接管 AbortError 单独记录，不误报为转换失败。
