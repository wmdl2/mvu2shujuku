## 追加校验时的元数据缺口

补充检查复现：`z.enum(['甲']).catch('').refine(...)` 被误判为未知输出，静态 `default`／`prefault` 参数也可能在追加校验后丢失。实际 Zod 克隆了定义对象，同时保留相同的 `catchValue` 函数或 `defaultValue` getter；旧转换器只按定义对象身份缓存参数。

修复在实际 API 捕获参数时同时记录提供器身份；序列化时通过属性描述符找回相同提供器的参数，不调用 getter 或回退函数，不推断函数源码。动态提供器仍不静态执行，原 `refine` 仍交由原 Schema 校验。此修复与上述样本合为一张根表无关。

公开回归覆盖静态 catch/default/prefault 追加校验、动态提供器不执行；浏览器实际工厂同样检查追加校验后的回退参数。当前包 SHA-256 为 `488072c9ba1ddabb5f19a9ce05e6c41c371653833e102e37dfde4e69477503d6`。构建与语法检查通过；完整公开回归 **894/0**，浏览器八项检查通过，外联请求零、残留 iframe 零、页面异常零。
