# v0.8.5 发布验收（2026-11-02）

本版收尾此前未发布的界面、Schema、历史性能及变量写入修复，并接入数据库已合并的两个公开接口。变更清单见[更新日志](../../CHANGELOG.md)，当前支持范围见[兼容清单](../../COMPATIBILITY.md)。下列前期记录中的“未发布”描述其受测时状态，本页汇总本次正式版本。

## 内容与升级

- 设置与转换结果界面重排，主题适配、报告复制、拖入文件、参数摘要、未保存保护及同一次转换规则快照统一；见[界面验证](2026-11-01-frontend-workflow.md)。
- 修复动态记录结构默认值重复JSON编码及无变化Schema初始化覆盖后续记录；保持原布局与作者规则。默认值编码修复需重转模板，运行时初始化修复更新扩展即可；见[Schema验证](2026-10-31-schema-defaults-and-initialization.md)。
- 历史准备缩小范围并合并在途请求，保留不受后续修改影响的前缀，减少重复复制和重复回放；来源／swipe／深层存储修订保护保留。见[范围与缓存](2026-11-01-history-preparation-performance.md)及[来源接口接入](2026-11-02-merged-database-apis.md)。
- 只接管宿主实际存在的裸变量接口，支持助手晚到；普通生成及助手消息操作衔接已接收的变量写入，重生成保留原生删楼语义。见[启动顺序](2026-11-02-helper-api-startup.md)及[写入边界](2026-11-02-pending-write-boundary.md)。
- 数据库1.3.4起提供来源身份和可选回读等待，本版按接口能力使用；在正式1.3.5验证。插件自己的支持路径跳过通知后的额外等待，旧宿主保留原调用。数据布局与存档位置不变，已有转换卡更新扩展后即可使用相应运行时优化。

## 保留边界

- 数据库与酒馆的慢保存成功确认缺口已受控复现；用户决定先暂缓，不在本版加入额外聊天回读、存档或上游修复PR。实际发生频率未知，不能把它标为已修复，详见[独立诊断](2026-11-02-merged-database-apis.md)。
- 写入衔接只等待已经进入适配层的任务，不能预测作者未来才发起的定时任务，也不接管任意私有聊天对象操作。
- 作者脚本语法错误、真实模型长期剧情质量、全部角色卡路线与未覆盖的其他宿主环境不属于本次通过结论。原卡脚本未修改，私有输入不作为公开回归依赖。
