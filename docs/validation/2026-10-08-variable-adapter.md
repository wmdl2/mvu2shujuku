## 实现与接口

原 EJS 执行器负责 JavaScript 表达式、作用域与执行顺序。转换时保留 `getvar/setvar`、消息别名的原调用，不再用静态调用替换处理这些接口；因此动态参数和同名局部函数都由原执行器解析。旧式直接读取入口仍使用既有兼容改写。原业务提示、统一填表说明、物理列与读写协议没有改成新方案。

运行时 `templateDatabaseDefines` 调用同一个 `createEjsEvalBridgeFactory.createVariableContext` 工厂，在宿主准备实际上下文后附加变量接口。普通变量及 `global/local/initial` 按原参数和 receiver 委派原生函数，仅数据库路径切换后端。`variables` 对象对 `stat_data` 提供视图，普通键保留原生引用，不修改宿主全局缓存。

| 接口 / 选项 | 当前处理 |
| --- | --- |
| `getvar/getMessageVar/setvar/setMessageVar` | 运行时解析动态路径，Lodash 处理数组、下标及含点字面键；undefined 删除 |
| `defaults/noCache/clone` | 缺失值使用 defaults；noCache 重读；clone 遵循宿主对应作用域分支，cache 读取并不保证克隆 |
| `index` | 处理字段中的 JSON 字符串，不是消息编号；保留宿主数值归一化与 cache/message 分支差异 |
| `flags/results/merge` | 字段存在性、作用域检查、old/new/fullcache 返回；数组追加、对象合并及嵌套数组替换 |
| `cache/dryRun` | 缓存修改不持久化；保留宿主 dryRun 门控。公共 evalTemplate 按宿主实际执行模式处理 |
| `withMsg` | 显式 message 读取按正负索引/原始角色规则选择；cache 读取与 cache 写入按原契约忽略此筛选 |
| 增减、插入、删除与 `patchVariables` | 共用适配读写；补丁解析/应用调用宿主公开接口，不另写 JSON Patch 执行器 |
| `variables[动态键]` | stat_data 读取数据库，其直接赋值仅改变本执行缓存；普通键使用原生对象 |
| MVU / 酒馆助手 message 读取 | 选定已有数据库帧；显式非 message 类型委派原公开接口 |

setter 只把目标字段合入当前权威数据，再走原有会话守卫与合并提交链。缓存中其他字段的修改或引用变更不会顺带保存。同步返回值表示计算结果，持久化仍由异步提交链完成；失败使用已有错误报告，不把同步返回当成保存确认。

## 历史与拒绝边界

历史读取按终点回放已有数据库帧，使用当前兼容布局。用户消息或未生成新帧的消息可继承此前有效快照；缺少消息、快照或兼容布局时返回缺失/defaults，不改读当前值。

写入限当前 AI 消息的选中 swipe。任意历史消息写入报 `MVU_HISTORY_WRITE_UNSUPPORTED`；未选中 swipe 报 `MVU_HISTORY_SWIPE_UNSUPPORTED`。包含 stat_data 的原生整份变量写入/根补丁报 `MVU_BULK_VARIABLE_WRITE_UNSUPPORTED`，不让原生存储绕过数据库。旧上下文切聊天后拒绝数据库操作；原型属性和无效 stat_data 根也拒绝。拒绝发生在修改原生变量或调用数据库提交前。

没有接管宿主完整内部变量缓存模块、所有辅助函数、作者缓存的旧函数引用或任意独立导入的私有实现。只保留源代码不能保证这些访问自动转接。这里没有实现任意历史回写、完整存档迁移或未选中 swipe 的独立数据库状态。
