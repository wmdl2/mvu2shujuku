# 提示词保真与定位说明的成本增量

使用本地 `o200k_base`，没有付费模型调用。保留必要说明、解决定位歧义优先于 token 减少。

## 同输入模板库存

计量各表 note、DDL、init/insert/update/delete 内容独立编码后的 token 之和。这些组件不一定
在一次请求中同时出现，不能视为完整请求或账单。每组均断言表名、顺序、数据和 DDL 完全一致。

| 样本与改动 | 修改前 | 修改后 | 净增量 |
| --- | ---: | ---: | ---: |
| 本地 15 表样本：字段/业务规则保真及示例修复 | 12,776 | 12,822 | +46（约 0.36%） |
| 同样本：本次特殊定位提示 | 12,822 | 12,931 | +109（约 0.85%） |
| 公开 5 表样本：本次特殊定位提示 | 1,777 | 1,966 | +189（约 10.64%） |

15 表样本两批合计净增 155 token，数据内容保持 595 token；公开样本的数据内容保持 218 token。
净增允许新增说明与已识别机械措辞的改写互相抵消，不表示只增加了这些数量的业务信息。
公开小样本中关系/数组占比更高，增幅更明显，不能外推所有卡。

## 基于实际请求的本批增量

请求来自[本批宿主验收](../validation/2026-09-15-prompt-guidance.md)，转换使用默认 both 模板。
仅把实际请求中的三处修改 note 换回此前文本，保持状态、协议、上下文、选表相同。
**修改后是真实捕获，修改前是文本重建，不是另一次实际请求。**

| SP 模式 | 重建的修改前正文 | 实际修改后正文 | 本批增量 |
| --- | ---: | ---: | ---: |
| native | 2,660 token | 2,849 token | +189（约 7.11%） |
| SQLite | 3,997 token | 4,192 token | +195（约 4.88%） |

SQL 注释包装使增量不同于模板库存。只计消息 content，不计 role/协议封装、输出、重试或供应商
账单差异。本次未重新测原 MVU 完整请求，不能据此宣称转换后整体更省或更费。

新增内容解释完整关联组合及三种编号，没有新增需填写的列或扩大数据输入。真实模型收益仍由
实际使用观察，不用删除必要业务说明来抵消这些增长。

## 复现

公开修改前模板冻结在 `docs/benchmarks/fixtures/prompt-guidance-before.json`，不含私有卡。

```sh
node -e "const fs=require('fs'); fs.mkdirSync('.tools',{recursive:true}); fs.writeFileSync('.tools/prompt-guidance-after.json',JSON.stringify(require('./src/mvu2shujuku').convert(require('./test/prompt-guidance-card')()).template));"
node test/measure-template-delta.js --before=docs/benchmarks/fixtures/prompt-guidance-before.json --after=.tools/prompt-guidance-after.json
```

捕获宿主请求后可追加 `--request=.tools/real-host/prompt-<mode>-filtered-<runId>.json`。工具要求
目标 note 恰好出现一次，且只有 note 差异；缺表、文本不匹配或其他字段变化时拒绝生成请求对照。
依赖见[开发指南](../development.md)，适用源码版本见上述验收记录。
