# 表格提示词与窗口枚举测量

本次使用公开合成卡，版本沿用[语义验收](../validation/2026-09-13-semantics.md)。
源码/社区对照已经完成；这里记录新增实现的成本证据，不重新执行历史审查。

## 结论与结构选择

表格会增加表头、定位键、协议和规则说明的输入成本。最终成本还取决于 SP 模式、选表、
行窗口、保留的世界书/EJS 和原始聊天上下文，不能拿表格 JSON 大小除以原始变量大小估算模型压力。
本次保留物理表，按逻辑父子关系将 `A表 → A_bag表 → B表 → B_bag表` 连续排列。
排序有助于一起查阅相关实体，但不会天然减少 token，也尚无模型质量提升证据。

没有仅凭名称前缀合并属性、背包、日志；这些数据有不同基数和删除规则。
父键/祖先键继续明确给出，脚本删父时清理后代行，减少无效旧数据留在表格中。
没有引入缺少跨表引用保障的“只发送活跃对象”过滤，也没有用未经测量的固定阈值自动拆大 JSON。
可空容器保持 JSON 是保存 null/缺失语义的取舍，native 叶子修改仍需输出完整单元格。
后续 SQLite 路径更新和明确固定附属对象合并的实施与对照，见 [2026-09-14 验收](../validation/2026-09-14-json-path.md)。

## 最终填表请求

运行 `2026-09-13T11-23-39-018Z`：6 张表，实际调用 SP 填表入口；请求在本地拦截，
按当前可见表/列或实际 DDL 返回固定更新指令。native、SQLite 各 1 次请求成功，
异步结束监听各执行 1 次，修正值重载可读，删楼恢复初值。

使用 `test/measure-prompts.js` 对已捕获请求逐条消息正文计算 `o200k_base` token：

| 模式 | 消息正文字符 | 消息正文 token | 含表格的消息 token | 原始 initvar token |
| --- | ---: | ---: | ---: | ---: |
| native | 3,945 | 2,321 | 1,304 | 77 |
| SQLite | 7,175 | 3,649 | 2,240 | 77 |

计数不含 role/协议封装及输出，不是供应商账单 token；更换模型 tokenizer 会改变数值。
“含表格的消息”也含 SP 包装与表规则，不等于数据行本身。SQLite 本样本更长主要来自
DDL 与协议文字，不能外推所有卡或据此判断质量更差。

实际表格投影排除了 `$private` 和 `_扩展数据`，保留可见的只读业务状态，列号与 SQL 标识符正确。
完整请求仍从聊天原文的 `<initvar>` 带入了一份初始状态，包括私有哨兵。
新版 SP 的“高手模式 → 填表规则 → 排除规则”可配置起始 `<initvar`、结束 `</initvar>`；
旧界面对应填表上下文的标签排除规则。每条规则只移除匹配的最后一对标签，多个块需另行核验。
转换器保留源消息供初始化，并在转换报告提示此问题，不擅自改动 SP 全局偏好。

运行 `2026-09-13T12-11-59-682Z` 用新 UI 的公开排除设置复验，命令
`node test/real-host.js --only=prompts --filter-initvar`；两种模式均 1 次请求、1 次业务监听，
重载及删楼通过，完整请求无私有哨兵，测试结束恢复原排除设置。最终正文计数如下：

| 模式 | 消息正文字符 | 消息正文 token | 含表格的消息 token | initvar 块 |
| --- | ---: | ---: | ---: | ---: |
| native | 3,753 | 2,245 | 1,304 | 0 |
| SQLite | 6,983 | 3,572 | 2,239 | 0 |

这是两次公开固定场景的实际捕获，少量表消息格式也有差异；不把全部 token 差额泛化为任意卡的收益。

保留的变量展示/EJS 可能与数据库正文重复，库存脚本会统计相关世界书入口；它不能仅凭正则
判断运行时是否被选入、展开几次。剧情生成请求与独立填表请求应分别检查。
本次未调用付费模型做多场景质量 A/B，也未测剧情生成的最终 token；这些实验不作为已完成指标。

## 窗口发现成本

公开内存夹具：100 个同源 iframe、30 次事件，每次 shim 与 emit 各获取窗口一次。
旧路径的等价计数为 120 次查询、枚举 12,000 个 iframe；这是按旧调用结构计算的计数，未测旧路径耗时。
当前 MutationObserver 路径为 1 次扫描、101 次查询、枚举 100 个 iframe、59 次缓存命中。
无观察器时保守回退，实测 60 次扫描、6,060 次查询、枚举 6,000 个 iframe。
导航、移除、同一同步轮新增、观察器失败和会话失效由行为回归覆盖。
内存夹具不证明真实前端端到端提速；缓存只保存窗口身份，事件参数和业务等待保持新鲜。
